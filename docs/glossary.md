# Glossary

- **Bicycle:** Station-bound vehicle and its availability metadata.
- **Dock controller:** Hardware-facing service issuing locking commands.
- **Ride:** Rider session with start and optional end timestamps.
- **Fare policy:** Strategy returning the complete payable quote for a ride.
- **Payment gateway:** Application contract for financial captures, independent of a payment processor.
- **Receipt:** Stable domain acknowledgement of a charge.
- **Repair queue:** Abstract submission destination for field service tickets.
- **Composition root:** Bootstrap package that wires concrete adapters to application ports.
